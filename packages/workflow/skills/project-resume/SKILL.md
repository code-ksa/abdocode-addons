name: project-resume
description: Resume the selected project using saved goals, actual files and verified checkpoints.
---
Identify the currently selected project and the saved original goal. Read available PLAN.md, NEXT_ACTION.md and project awareness notes through authorized tools; missing notes are not permission to create a new project. Compare checkpoints to current files and Git changes before deciding what remains. Preserve the user's database choice, chosen project location and completed work. Carry forward acceptance criteria, run the next unfinished step, and record measured results. A previous success statement is not proof that current files still satisfy it. If the selected project cannot be established, ask the user which project to resume. Never substitute a hardcoded username or path.
